# Dice Battler

A dice roguelike. Roll your die to battle opponents, collect power-ups (die
upgrades, stacking modifiers, one-offs, and permanents), defeat bosses, and
climb as far as you can.

Live at **[dice.nilmamano.com](https://dice.nilmamano.com)**.

## Tech

- Next.js 15 (App Router) + React 19
- TypeScript, Tailwind CSS, shadcn/ui
- Deployed on Vercel

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```
